# Beceri lisansları

Bu klasördeki Claude Code becerileri üçüncü taraf çalışmalarıdır; LS19'un kendi kodu değildir ve siteye girmez (`.vercelignore`). Kaynaklar ve lisans bildirimleri aşağıdadır.

## Emil Kowalski becerileri (14 beceri)

`animate`, `animate-expo`, `animation-vocabulary`, `apple-design`, `ask-sonner`, `break-ui`, `emil-design-eng`, `find-animation-opportunities`, `improve-animations`, `mobile-native`, `pick-ui-library`, `prototype`, `review-animations`, `write-swift`.
